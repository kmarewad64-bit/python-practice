# Smart Scholarship & Government Scheme Finder

## Project Description

This project is a Python-based scholarship finder that collects scholarship information from the official National Scholarship Portal (NSP), stores the data in CSV format, and helps students find potential scholarship matches.

## Features

- Web scraping of scholarship data
- Student information input
- State-based scholarship matching
- Education-level matching
- Application deadline tracking
- Active, Due Soon and Expired status
- Streamlit web interface
- CSV-based data storage
- Refresh latest scholarship data option

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Streamlit
- CSV

## Data Source

National Scholarship Portal (NSP)

https://scholarships.gov.in/
